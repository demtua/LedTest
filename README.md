# Hot flash — LED-ების ტესტი ESP32-ზე

ESP32 კომპიუტერს USB კაბელით უკავშირდება. `start` ბრძანებაზე ხუთი LED რიგრიგობით ინთება, შემდეგ კი საპირისპირო თანმიმდევრობით ქრება („სიმხურვალის ტალღის“ იმიტაცია). `stop` ყველაფერს მყისიერად თიშავს. თუ 10 წამის განმავლობაში ახალი ბრძანება არ მოვა, ESP32 არხს თავად გათიშავს.

## ფაილები

| ფაილი | დანიშნულება |
|---|---|
| `hotflash/hotflash.ino` | ESP32-ის კოდი (იტვირთება Arduino IDE-ით) |
| `hotflash_client.py` | კომპიუტერის კლიენტი, რომლითაც ბრძანებებს აგზავნით |
| `requirements.txt` | საჭირო Python ბიბლიოთეკები (`pyserial`) |

## შეერთება

ხუთი LED უერთდება GPIO 4, 16, 17, 5 და 18 პინებს, ამ თანმიმდევრობით: პირველი ინთება GPIO 4-ზე, ბოლო GPIO 18-ზე.

თითოეული LED-ის გრძელი ფეხი (+) უერთდება პინს, მოკლე ფეხი (−) კი GND-ს. რეკომენდებულია, თითოეულ LED-თან მიმდევრობით ჩართოთ 220 Ω რეზისტორი, ვიდეოში წარმოდგენილ LED-ებთან აუცილებელი არ არის.

## 1. Python-ის მხარე

ყველა ბრძანება გაუშვით ტერმინალში, პროექტის საქაღალდიდან.

### ვირტუალური გარემოს შექმნა (მხოლოდ პირველად)

თუ საქაღალდეში `venv` ჯერ არ არსებობს:

```powershell
python -m venv venv
```

### ვირტუალური გარემოს გააქტიურება

Windows (PowerShell):

```powershell
.\venv\Scripts\Activate.ps1
```

Windows (Command Prompt):

```bat
venv\Scripts\activate.bat
```

Linux / macOS:

```bash
source venv/bin/activate
```

გააქტიურების შემდეგ ბრძანების ხაზის დასაწყისში გამოჩნდება `(venv)`.

თუ PowerShell წერს, რომ სკრიპტების გაშვება აკრძალულია, ერთხელ გაუშვით:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### საჭირო ბიბლიოთეკების ინსტალაცია

```powershell
pip install -r requirements.txt
```

### აპლიკაციის გაშვება

1. შეაერთეთ ESP32 კომპიუტერთან USB კაბელით.
2. პორტის გასარკვევად გაუშვით კლიენტი პორტის მითითების გარეშე. ის ჩამოთვლის ხელმისაწვდომ პორტებს:

   ```powershell
   python hotflash_client.py
   ```

   ESP32 ჩვეულებრივ ჩანს როგორც `Silicon Labs CP210x USB to UART Bridge (COM8)`.

3. გაუშვით კლიენტი ამ პორტით (Linux-ზე, მაგალითად, `/dev/ttyUSB0`):

   ```powershell
   python hotflash_client.py COM8
   ```

### ბრძანებები

| ბრძანება | რას აკეთებს |
|---|---|
| `start` | იწყებს LED-ების მიმდევრობას |
| `stop` | მყისიერად აჩერებს მიმდევრობას და თიშავს LED-ებს |
| `help` | აჩვენებს ბრძანებების სიას |
| `quit` | ხურავს კლიენტს (Ctrl+C-იც იგივეს აკეთებს); |

ESP32-ის პასუხები ეკრანზე `<<`-ით იწყება, მაგალითად `<< OK START`.

## 2. ESP32-ზე კოდის ატვირთვა Arduino IDE-ით

1. დააინსტალირეთ Arduino IDE 2: <https://www.arduino.cc/en/software>
2. დაამატეთ ESP32-ის მხარდაჭერა:
   - **File → Preferences** → ველში **Additional boards manager URLs** ჩასვით:
     `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
   - **Tools → Board → Boards Manager**, მოძებნეთ `esp32` და დააინსტალირეთ **esp32 by Espressif Systems**.
3. გახსენით სკეჩი: **File → Open** → `hotflash/hotflash.ino`.
4. აირჩიეთ დაფა: **Tools → Board → esp32 → ESP32 Dev Module**.
5. აირჩიეთ პორტი: **Tools → Port** → ESP32-ის პორტი (მაგალითად `COM8`).
6. დახურეთ Python-ის კლიენტი და Serial Monitor. პორტის გამოყენება ერთდროულად მხოლოდ ერთ პროგრამას შეუძლია.
7. დააჭირეთ **Upload** ღილაკს (ისარი →). ატვირთვა დასრულებულია, როცა ქვედა ფანჯარაში გამოჩნდება `Hard resetting via RTS pin...`.

თუ ატვირთვა ჩერდება წარწერაზე `Connecting.....`, დააჭირეთ დაფაზე **BOOT** ღილაკს და გეჭიროთ, სანამ ატვირთვა არ დაიწყება.

ESP32-ის შემოწმება Python-ის გარეშეც შეიძლება: **Tools → Serial Monitor**, სიჩქარე **115200 baud**, ხაზის დასასრული **Newline**, შემდეგ აკრიფეთ `START`.

## უსაფრთხოების ავტომატური გათიშვა (დროის ზღვარი)

- დროის ზღვარი: **10 წამი**.
- „არხი“ არის კავშირი კომპიუტერსა და ESP32-ს შორის. ყოველი სწორი ბრძანება (`start`, `stop`) არხს ღიად ინახავს და ტაიმერს თავიდან იწყებს.
- თუ 10 წამის განმავლობაში ახალი ბრძანება არ მოვა, ESP32 თავად ხურავს არხს: აჩერებს მიმდევრობას, თიშავს LED-ებს და აგზავნის `CUTOFF no command for 10000 ms`. კლიენტი ამ შეტყობინებას აჩვენებს, წერს `Connection closed.` და იხურება.
- გათიშვა მუშაობს მაშინაც, როცა კლიენტი დაიხურა ან კავშირი გაწყდა: ESP32-ს გასათიშად კომპიუტერი არ სჭირდება.
- გათიშვას მხოლოდ ESP32 წყვეტს; კლიენტს საკუთარი ტაიმერი არ აქვს. ზღვრის შესაცვლელად შეცვალეთ `CUTOFF_MS` ფაილში `hotflash/hotflash.ino` (მილიწამებში) და ხელახლა ატვირთეთ კოდი ESP32-ზე.

## ხშირი პრობლემები

- **`could not open port ... Access is denied`** — პორტი სხვა პროგრამას უკავია (მაგალითად Arduino IDE-ის Serial Monitor-ს ან კლიენტის მეორე ფანჯარას). დახურეთ ის და თავიდან სცადეთ.
- **ESP32-ის პორტი სიაში არ ჩანს** — დააინსტალირეთ CP210x დრაივერი: <https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers>. ასევე შეამოწმეთ, რომ USB კაბელი მონაცემებს გადასცემს (ზოგი კაბელი მხოლოდ დასამუხტია).
